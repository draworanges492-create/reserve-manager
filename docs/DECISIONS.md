## After Phase 0 feedback (2026-10-19)

| #   | Topic                      | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Source                                                                                 |
| --- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| D11 | Fill the screen            | Zoom = largest whole number at which 640×360 fits; the canvas then widens/heightens to fill the whole window at that zoom (no black bars). A MacBook Pro 14" browser window (~1512×865) runs at 2× with a 756×432 view; 16" (~1728×1000) at 2× with 864×500. Wider screens see more map, never a blurred image.                                                                                                                                                                                                                                            | User ("fit my MacBook Pro screen")                                                     |
| D12 | More pixel detail          | Tiles **24×24** (spec: 16), animals **24×24 / 48×48** (spec: 16/32), minimum view **640×360** (spec: 480×270). Tiles appear the same size on screen as before but hold ~2.3× the detail. Portraits scaled to match: **72×72** (spec: 48). `docs/SPEC.md` updated.                                                                                                                                                                                                                                                                                          | User chose "24px tiles"                                                                |
| D13 | Animals vs map readability | Rules for all placeholder and final art, starting Phase 1: (1) map uses a muted, low-saturation, low-contrast palette with no outlines; (2) animals use saturated colours that do not appear in the map palette and always have a 1 px dark outline; (3) every animal sprite has a soft dark ground shadow; (4) animal sprites gently bob/animate even when idle, since motion separates them from static terrain; (5) on hover, an animal group shows a light highlight ring and its species + count label. These go into `docs/ART_GUIDE.md` in Phase 1. | Claude (from user request: "make it clearer to differentiate between animals and map") |

## Phase 1 (2026-10-19)

| #   | Topic              | Decision                                                                                                                                                                                                                                                                                                                                                                                                 | Source                         |
| --- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| D14 | Camera zoom        | World camera zoom steps **0.5×, 1×, 2×, 3×** (default 1×) instead of spec §5's 2×–4×. That range assumed 480×270 with no screen zoom; on top of our 2× screen zoom it would show only 8–15 tiles. 1× shows ~31×18 tiles on a MacBook; 0.5× is an overview.                                                                                                                                               | Claude                         |
| D15 | Map made by script | `tools/generate-map.ts` writes `reserve.tmj` from `tools/map/layout.ts` (seeded, so identical every run). It refuses to overwrite without `--force`, because that would discard edits made in Tiled. Once you edit the map in Tiled, treat the .tmj as the source and stop regenerating.                                                                                                                 | User (script) + Claude (guard) |
| D16 | Zone layout        | Zones placed as non-overlapping rectangles close to spec sizes (outcrop 25×20, plains 40×30, …). ~40% of the map is **unzoned buffer bush** (the spec's sizes add up to 5,800 of 9,600 tiles); it is not hoverable. The river runs north–south down the west side; the village (huts, crop strips) sits on the far east edge of the Eastern Border. HQ is at the south with the gate on the south fence. | Claude                         |
| D17 | Zone data location | Names and unlock chapters live in `src/data/zones.json`; the map holds only geometry and ids. `validate-data` cross-checks both ways.                                                                                                                                                                                                                                                                    | Claude                         |
| D18 | UI text            | Crisp text at device resolution in the system monospace font, not a pixel font, for legibility. No font file is bundled yet; an OFL pixel font can be swapped in later.                                                                                                                                                                                                                                  | Claude                         |
| D19 | Tile labels        | Spec §12 says "labeled" placeholder tiles. Only **buildings** carry labels (HQ, RP, GT, PU); terrain is unlabelled so the map stays calm and animals stay readable (D13). Tile names are listed in `docs/ART_GUIDE.md`.                                                                                                                                                                                  | Claude                         |
| D20 | Locked zones       | Dimmed from Phase 1, using zones.json `unlockChapter` vs a fixed `START_CHAPTER = 1` until GameState exists (Phase 2). Fences start drawn as broken/dashed.                                                                                                                                                                                                                                              | Claude                         |
| D21 | Early core files   | `core/Rng.ts` (needed for seeded map generation) and `core/EventBus.ts` (zone hover → HUD) were created in Phase 1 rather than Phase 2.                                                                                                                                                                                                                                                                  | Claude                         |
| D22 | Preview animals    | Small static groups of impala, zebra and lion at the map's animal spawn points, so readability can be judged now. Phase 4 replaces them with population-driven wandering groups.                                                                                                                                                                                                                         | Claude                         |
| D23 | Extra map data     | Waterholes, build slots and fence segments also carry a `zoneId` property, and build slots a `slotId`, so later phases can find them by name. Pump slots sit at **both** waterholes (A: the old sabotaged pump; B: the river pump site).                                                                                                                                                                 | Claude                         |
| D24 | UI strings         | Player-facing UI text lives in `src/data/strings.json` (looked up with `t()`), to keep text translatable as spec §16 asks.                                                                                                                                                                                                                                                                               | Claude                         |
| D25 | Edge scroll        | On by default, mouse only (never touch), and paused while dragging. May need a settings toggle once the HUD exists (Phase 6).                                                                                                                                                                                                                                                                            | Claude                         |
