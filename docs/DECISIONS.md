## Phase 4 (2026-10-19)

| #   | Topic                | Decision                                                                                                                                                                                                                                                                                                                                                                                    | Source                                     |
| --- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| D50 | Grazing scale        | Spec §6.2's `grazing = Σ(N × grazeRate) / zoneTiles` gives ~0.001 points/day for 80 impala, so grass could never run down (and Ch 3's "impala boom strips vegetation" couldn't happen). `grazeRate` is read as % of one tile eaten per animal per day, times `balance.vegetation.grazingScale` = **250**, tuned with `sim:balance` so an attentive player's plains swing ~51–65% by season. | Claude                                     |
| D51 | Saturating predation | Spec's flat `killsPerDay` is scaled by prey / (prey + `huntHalfSaturation`), so hunting slows as prey thins instead of wiping herds out. Lion: 0.06 impala + 0.02 zebra per lion per day at most, half-rate at 20 prey, `predationEfficiency` 0.04 (lions supported per prey animal). **Guesses** — tune freely.                                                                            | Claude                                     |
| D52 | Stochastic rounding  | Births, starvation and each predator's kills are rounded to whole animals separately (up with probability = the fraction), using the seeded RNG in a fixed order (zones by id, species by species.json), so results are deterministic and the panel can say "+3 born · 1 starved · 2 taken by lions". Losses never exceed the herd.                                                         | Claude                                     |
| D53 | No capacity          | With carrying capacity 0 (e.g. predators with no prey), a herd shrinks at its growth rate plus the overshoot die-off, rather than vanishing in one day.                                                                                                                                                                                                                                     | Claude                                     |
| D54 | Starting values      | Lions start at **4** (was 3): at 3 they were below `minViable` and could never breed. Starting vegetation per zone in zones.json (`startVegetation`: plains 55, river 80, woodland 75, north 70, east 60, outcrop 45, HQ 40).                                                                                                                                                               | Claude                                     |
| D55 | Why log in state     | `GameState.populationLog` keeps last day's births / starved / eatenBy / capacity per herd, so the panel can explain the number after the tick. Vegetation's why is computed live (`vegetationBreakdown`).                                                                                                                                                                                   | Claude                                     |
| D56 | Zone panel           | Clicking open ground (not a drag) opens that zone's panel: grass %, Healthy/Degraded, regrowth vs grazing per day, water, animals. Replaces "click ground to close". Herd and zone panels share one bottom-left slot; × or Esc closes. Selected zone gets a solid outline.                                                                                                                  | Claude (spec §4 Phase 4 "zone info panel") |
| D57 | Neglect is harsh     | With no refills, Waterhole A is dry, the plains support ~34 impala, and the herd falls 80 → ~45 in about 10 days (≈ 20 min at 1×). That's the pressure behind Chapter 1's chore; soften via `balance.population.noWaterFactor` (0.3) or `overshootDeathRate` (0.05) if it feels punishing.                                                                                                  | Claude (flag for playtest)                 |
